# Glass Tavern

Mac・スマートフォン向けの日本語キャラチャット。Cloudflareで独立稼働するアプリです。SillyTavern本体のフォークではなく、カード・会話のインポートとエクスポートに対応します。

## 開発

Node.js 22 LTS を使用します。

```sh
npm ci
cp .env.example .dev.vars
# .dev.vars に APP_ORIGIN=http://localhost:4197 を追加
# KEY_ENCRYPTION_SECRET は openssl rand -base64 32 で作成（公開しない）
npm run build
npm run db:local
npm run dev:api
# 別のターミナル
npm run dev
```

`http://localhost:4197` を開きます。`DEV_AUTH=true` とループバックホストの両方を満たす場合だけ、ローカルテストログインとAI生成なしのモックが使えます。本番でDEV_AUTHを設定しないでください。

## Cloudflare

`wrangler.jsonc` のD1を自分のDBに変更して、`APP_ORIGIN` を実際のHTTPS公開元に合わせます。Google CloudでWebアプリのOAuthクライアントを作成し、コールバックを `{APP_ORIGIN}/auth/callback` に登録します。`GOOGLE_CLIENT_ID` は変数、`GOOGLE_CLIENT_SECRET` と32バイトbase64の `KEY_ENCRYPTION_SECRET` は `wrangler secret put` で設定します。

```sh
npx wrangler d1 migrations apply glass-tavern --remote
npm run build
npx wrangler deploy
```

APIキーを変更せずに暗号化キーを破棄すると復号できません。鍵の更新には既存キーの再暗号化が必要です。HTTPSでのみ運用してください。料金と利用制限は各AI事業者の条件に従います。

## 確認

```sh
npm run typecheck
npm test
npm run build
```

モックの返答は実AI接続の合格には数えません。Google OAuthと各AI実生成は有効な資格情報を用いた別の確認が必要です。

## 互換性

- SillyTavern V2/V3 JSON、PNG `tEXt` 内の `chara` / `ccv3` カードを読み込みます。
- 未知のカードフィールドを `source` に保持して書き出しへ戻します。キャラ設定・挨拶・名前を編集できます。
- JSONL会話のヘッダーメタデータ、本文、発話ロールを保持します。メッセージごとの未知フィールド・日時・swipes・extraも保持します。ステータスはヘッダーの独自拡張へ保存します。
- personality、scenario、system_prompt、post_history_instructions、mes_example と常時有効のロア項目をプロンプトへ含めます。
- キーワード発火のLorebook、マクロ展開、正規表現拡張、SillyTavern本体のグループチャット形式・複数モデル個別呼び出し、ST専用プリセットは実行しません。値はカード内に保持されます。
- PNG内の画像は最大512pxのJPEGサムネイルとして読み込みます。編集画面で300KB以下の画像も追加できます。
- JSONカードは5MB以下、保存キャラ全体はUTF-8 1MB以下、会話はUTF-8 1.5MB以下です。
- ステータスはAIの返答にJSONが含まれる場合に検証して更新します。非対応のモデルは本文表示のみになります。

## ライセンス

AGPL-3.0-or-later。SillyTavernのコードやアセットは含めていません。SillyTavern互換フォーマットへの対応は独立実装です。SillyTavernはその開発者によるAGPL-3.0のプロジェクトです。Zeta / チャチャとは関係のない独立アプリで、名称・画像・文章・コードを複製しません。

## 作品と複数キャラクター

作品には題名・世界観プロンプト・キャラクター一覧・イントロを設定します。各人物は名前、画像、プロンプト、独立したステータスを持ちます。既存の単一キャラは同じIDの作品へ読み取り時に変換し、会話ID・保存履歴・ステータスIDを保持します。DBの破壊的な移行はありません。

返答の `@名前: 台詞`（全角コロンも可）には対応する人物の名前と画像が表示されます。`@: 地の文` と `*地の文*` はナレーションです。1応答で複数人物を表示できます。未知の名前には他の人物の画像を流用せず、名前だけを表示します。HTMLは実行しません。閉じていないアスタリスクは普通の文字として残します。

作品は最大12人、1人12ステータス・作品全体48ステータスです。名前の空欄・重複とID重複を拒否します。画像は1人300KB以下、保存作品全体は従来どおりUTF-8 1MB以下です。複数の大きな画像がある場合は小さい画像を使ってください。

SillyTavernカードの `extensions.glass_tavern.story` に世界観・全キャスト・イントロを保存します。未知の元フィールドも保持します。他のアプリがこの独自拡張に未対応の場合、全キャストを再現できないことがあります。SillyTavernの単一キャラカードを読み込む場合は1人の作品になります。

以前の版で使えた `@`・コロン・アスタリスク・改行を含む名前も、保存済み作品の一覧と編集ではそのまま読み込みます。自動で改名しません。新しい会話構文と衝突するため、再保存時は人物名の該当文字を修正してください。編集画面には元の名前と修正案内を表示し、題名・会話履歴は変更しません。読み込み時には新しい画像・合計サイズ制限も再適用せず、保存時に検証します。

### ナイトモード
設定の「表示」、または会話画面の月／太陽ボタンで切り替え。黒背景・白文字、ユーザー発言は紫、キャラクター発言は濃いグレー、地の文はグレー。編集・設定・スケルトンにも適用します。初回は端末の配色設定に従い、手動選択はブラウザごとに保存します。

## Zetaからの移行

「Zetaから読み込む」で、自作作品のバックアップZIP（または `plot.json`）と、拡張の「Glass Tavernへ書き出す」で保存した会話JSONを別々に選択できます。作品だけ・会話だけでも読み込めます。作品は公開ルート設定を採用し、`draft` は採用しません。複数イントロは先頭を使い、その旨を表示します。画像URLは取得・描画せず省略を通知します。画像は手動追加してください。他作者の会話には非公開の世界観・人物設定が含まれないため、プレビューで手入力します。

プレビューで作品名・世界観・人物・イントロ・キーワード設定・ユーザー操作人物名・続きのメモを編集できます。保存は認証済みユーザーに紐付けた作品と会話を単一D1バッチで作成します。失敗時は両方ロールバックされます。既存作品や会話は変更しません。履歴配列の順序とIDを保持し、重複ID、不明な役割、2000件超・UTF-8 1.5MB超を拒否します。HTTP全体は既存の1.8MB制限があり、作品設定が大きい場合は合計でも制限されます。切り捨て保存はしません。

履歴JSONの契約は `{format:"zeta-glass-tavern",version:1,kind:"history",roomId,title,exportedAt,messages:[{id,role:"user"|"assistant",content}],warnings:[]}` です。`exportedAt` はUTC ISO日時。書式のない画面コピーは対象外です。元room ID・題名・日時・警告は会話メタデータ、元plot ID・lorebook ID/題名は作品sourceに保持します。取得元の不要な認証情報やdraft、画像URLは持ち込みません。

生成に送る履歴は直近60件です。続きのメモと操作人物名は毎回systemへ反映し、ユーザーの発話や行動をAIに決めさせない指示に含めます。キーワード設定は直近10件に大文字小文字を無視した文字列一致で発火します。正規表現は使いません。キーワード空欄は常時有効。sequence順、同順位は入力順で合計UTF-8 24KB以内を採用し、超過する項目はその回の生成から除きます。設定は100件まで、1件6000文字・キーワード30個までです。操作人物名・メモ・キーワード設定はGlass Tavernカード拡張にも書き出し、再読み込みできます。


Zeta拡張の連携追加差分は `docs/zetaweb-plus-transfer.patch`。既存の全履歴取得を再利用し、新しい権限や自動アップロードは追加しません。書き出しは端末内のJSONファイルです。取り込み前のプレビューはブラウザ内で処理し、保存ボタンでログイン中のアカウントへ保存します。

ZIPは既存拡張が作る無圧縮形式のみを、30MB上限・plot.jsonのCRC確認付きで読みます。追加ライブラリを入れず、画像を取得せず、ファイルを展開せずに作品情報だけを取り出すためです。人物画像は現在省略され、必要な画像を編集から追加できます。
