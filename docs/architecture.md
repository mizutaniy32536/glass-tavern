# 技術選定と設計

| 技術 | 選定理由 |
|---|---|
| TypeScript | UIとWorkerで型を共有し、会話・ステータスの型のずれを検知するため。 |
| React 19 | フォーム・会話・モーダルなど状態の多い画面を組み立てやすく、保守できる人も多いため。 |
| Vite | ブラウザへ配る静的資産を短時間でビルドし、Workerと分けてUI開発できるため。 |
| Cloudflare Workers | Macを起動していなくても動作するサーバー、秘密のAPIキー、Google認証処理をまとめるため。 |
| Hono | Worker向けに軽量なルーティング・Cookie・ミドルウェアを使えるため。 |
| D1 / SQLite | ユーザーごとのキャラ・会話・設定をSQLで分離し、Cloudflare内に保存するため。 |
| Workers Static Assets | フロントとAPIを同一オリジンで配信し、CORSやCookie設定の複雑さを減らすため。 |
| Google OIDC + jose | Googleログインだけに絞り、公開鍵署名・issuer・audience・nonceを検証するため。認可コード＋PKCE＋stateを使用。 |
| Web Crypto AES-GCM | APIキーを暗号化して保存し、改ざんを検知するため。外部暗号ライブラリと独自暗号を避ける。 |
| Zod | 入力・カード・ステータスの境界で同じ検証ルールを使うため。 |
| Motion | カード・画面・モーダルの動きを調整し、OSの「視差効果を減らす」に従うため。 |
| CSS backdrop-filter | 白黒基調のガラス表現を画像に依存せず実装し、レスポンシブにするため。 |
| Lucide | ボタンの意味が読み取りやすい一貫した線画アイコンを使うため。 |
| Vitest | 入力検証・暗号・認証境界・互換性を速く自動確認するため。 |
| Wrangler | Cloudflare公式のローカル実行・マイグレーション・公開手段を使うため。 |

## 境界

ブラウザはAPIキーを入力した保存要求にのみ含めます。サーバーはランダムnonce付きAES-GCMで保存し、レスポンスに返しません。localStorageにはキーや認証情報を保存しません。Googleの認証トークンもブラウザへ返しません。セッションはランダム値のハッシュをD1に保存し、HttpOnly・SameSite=Lax・本番Secure Cookieで参照します。

全ユーザーデータ操作に認証ユーザーのowner条件を付けます。変更APIはOriginを検査します。D1の会話ロックで90秒間の並行生成を防ぎます。生成は最大60秒で中断し、失敗時はユーザー入力を画面に残します。生成中の編集をサーバーで拒否します。送信IDごとの処理結果を保存し、同じ送信の再試行は保存結果を返します。停止操作は生成IDを失効させ、後から返る本文の保存を防ぎます。外部AIの処理・課金停止は保証しません。再生成では前回返答の直前のステータスへ戻します。長い会話では直近60件をプロンプトへ送ります。モデルに個人情報を送るかはユーザー自身で選択してください。

D1に小さい画像を保存する構成です。画像はPNG/JPEG/WebP・300KB以下。R2は将来の大容量メディア拡張候補ですが、今回のアカウント権限で必須にしません。ストリーミングやグループ会話は今回の実装範囲外です。

Googleログイン・暗号化キーが未設定でもローカルでの画面テストはできますが、本番認証は失敗で閉じます。管理者が公開URLのGoogle OAuthと実AI生成を別途確認する必要があります。
